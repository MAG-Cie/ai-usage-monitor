Frequently asked

How do you read my "real" spend?

Through each provider's official billing/usage APIs (Anthropic Admin API, OpenAI Organization costs, OpenRouter Activity, Gemini BigQuery billing). It's the billed amount, not an estimate.

Are my API keys safe?

Yes. They're OS-encrypted (Windows DPAPI via Electron safeStorage) before touching disk, never logged, and only sent to their own provider's API.

Is there a subscription?

No. Pro is a one-time purchase (€14.99) with 2 activations and updates included. Free stays free indefinitely.

Does Windows warn on launch?

Early builds aren't signed with an OV certificate yet, so SmartScreen may show "unknown publisher". The installer scans 0 detections on VirusTotal; click "More info → Run anyway".

What about macOS / Linux?

Windows ships first; macOS and Linux are under consideration.

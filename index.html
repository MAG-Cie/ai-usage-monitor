Le vrai chiffre

L'estimation ment. La facture, non.

Questions fréquentes

Comment lisez-vous ma « vraie » dépense ?

Via les API officielles de facturation/usage de chaque provider (Admin API Anthropic, Organization costs OpenAI, Activity OpenRouter, BigQuery billing Gemini). C'est le montant facturé, pas une estimation.

Mes clés API sont-elles en sécurité ?

Oui. Elles sont chiffrées par l'OS (Windows DPAPI via Electron safeStorage) avant d'atteindre le disque, ne sont jamais journalisées, et ne sont envoyées qu'à l'API de leur propre provider.

Y a-t-il un abonnement ?

Non. Pro est un achat unique (14,99 €) avec 2 activations et les mises à jour incluses. La version Free reste gratuite indéfiniment.

Windows affiche un avertissement au lancement ?

Les premières versions ne sont pas encore signées avec un certificat OV, donc SmartScreen peut afficher « éditeur inconnu ». L'installeur est scanné 0 détection sur VirusTotal ; clique « Informations complémentaires → Exécuter quand même ».

Et macOS / Linux ?

La version Windows est disponible en premier ; macOS et Linux sont à l'étude.

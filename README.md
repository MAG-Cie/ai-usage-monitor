# AI Usage Monitor

Track your **real AI spend** across providers (Anthropic, OpenAI, OpenRouter,
Gemini) — billed cost vs estimate, in a 100% local Windows widget. No telemetry,
no backend.

**Website:** https://mag-cie.github.io/ai-usage-monitor/
**Download:** [latest release](https://github.com/MAG-Cie/ai-usage-monitor/releases/latest)

This repository hosts the **landing page and release binaries** only. The
application source is proprietary and not published here.

- Free: 1 provider. Pro (€14.99, 2 seats): unlimited providers, budget alerts,
  unlimited history.
- Privacy: keys are OS-encrypted (Windows DPAPI); the app contacts only your
  configured provider APIs, GitHub (updates) and Lemon Squeezy (license).

Politique de confidentialité

Dernière mise à jour : août 2026. Responsable du traitement : MAG&Cie — Antoine Guittet (antoine.guittet@mag-cie.com).

Principe : local d'abord, aucun serveur nous appartenant

L'application AI Usage Monitor fonctionne sur votre poste. Nous n'exploitons aucun serveur, aucune télémétrie, aucun analytics, aucun compteur d'installations. Vos données d'usage restent sur votre machine.

Données traitées par l'application

  • Clés API / identifiants providers : saisis par vous, chiffrés par le système d'exploitation (Windows DPAPI via Electron safeStorage), stockés localement, jamais journalisés, jamais transmis à nous.
  • Données d'usage et de coût : récupérées depuis les API des providers que vous configurez, stockées localement (historique de dépense).

Ces données ne transitent jamais par un service nous appartenant.

Destinataires (sous-traitants)

  • API des providers configurés (Anthropic, OpenAI, OpenRouter, Google) — pour lire votre propre usage.
  • GitHub — hébergement de ce site et distribution des mises à jour de l'application.
  • Lemon Squeezy — vente, facturation et validation des licences Pro (merchant of record). Les données de paiement sont traitées par Lemon Squeezy, pas par nous.

Ce site web

Ce site est statique et n'utilise ni cookie ni traceur. Aucune donnée de navigation n'est collectée par nos soins. Votre navigateur peut établir des connexions techniques vers GitHub (hébergement).

Liste d'attente / contact

Si vous nous écrivez (liste d'attente macOS, support), votre adresse e-mail n'est utilisée que pour vous répondre ou vous informer de la disponibilité, et n'est jamais revendue.

Vos droits (RGPD)

Vous disposez d'un droit d'accès, de rectification, d'effacement et d'opposition sur les données que vous nous auriez communiquées. Pour l'exercer : antoine.guittet@mag-cie.com. Les données stockées localement par l'application peuvent être supprimées en désinstallant l'application ou en vidant son dossier de données.
